# Cereal 1 — Guide

Oct 26, 2026 · Anas Alsirafy

The cereal track detects foliar diseases on field photos of maize, where one photo can show several diseases at once. The best model so far is a single ConvNeXt-Base with per-label thresholds (macro-F1 0.468); a five-specialist redesign scored lower (0.283) and is unresolved. This set is for a new team member with basic AI knowledge.

## Where this sits

This handover has three parts. This set covers maize. The cassava classifier, where the training pipeline was first developed, has its own eight docs starting at [Cassava 1 — Guide](https://github.com/Anas-Alsirafy/cassava-leaf-disease-classification/blob/main/docs/Cassava_1_Guide.md). The five-dataset comparison behind Paper 2 is one doc: [Cross-Dataset Study — Five Datasets (Paper 2)](https://github.com/Anas-Alsirafy/leaf-disease-cross-dataset-study/blob/main/docs/Cross_Dataset_Study.md). Rice is a cereal but was only used in that comparison, so it lives there.

## Glossary

| Term | Meaning here |
| --- | --- |
| Multi-label | An image can have several labels at once. The model has one sigmoid output per label, each answering yes/no independently. |
| Weighted BCE | Binary cross-entropy where positives of rare labels count more: pos_weight = (N − positives) / positives, capped at 50. |
| Threshold tuning | Choosing, per label, the probability above which we say "yes" (instead of 0.5). |
| OOF predictions | Each image's prediction from the fold where it was held out. |
| Macro-F1 / micro-F1 | Macro averages F1 over labels equally; micro pools all decisions, so common labels dominate. |
| Hamming loss | Fraction of all (image, label) decisions that are wrong. Lower is better. |
| Monolithic | One network predicting all 8 labels. |
| Specialist | A smaller model trained on one sub-problem (e.g. healthy vs gray leaf spot); outputs are combined. |
| Three-phase training | Frozen backbone → top 30 layers unfrozen → whole network unfrozen. |
| MultilabelStratifiedKFold | A fold splitter that keeps every label's share roughly equal across folds. |
